# 他山 Logo

`tashan-logo-original.png` 是用户提供的「他山logo.png」原文件，1254 × 1254，保留原图案、颜色与背景。

界面统一使用 `assets/brand/tashan-logo.webp`（192 × 192），浏览器页签使用 `favicon-32.png`，设备快捷方式使用 `apple-touch-icon.png`。这些文件仅等比缩小与编码，不裁切、不重绘或更改配色。主导航、登录与重播动效、加载状态、作品预览和仓库介绍均使用同一来源。

发布脚本包含轻量展示文件；原始 PNG 只作为仓库中的品牌源文件保存。资源版本脚本同步更新图片和引用它的脚本、页面，避免客户端继续显示旧标识。
