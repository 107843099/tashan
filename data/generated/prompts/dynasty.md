# 朝代课堂知识海报提示词模板

> 用法：只替换所有 `【】` 中的内容，即可生成其他朝代的课堂海报。每个核心知识卡都要包含“知识点 + 一句话记忆解析”。

- 不使用照片拼贴，不使用 3D 字，不使用霓虹色，不加 logo，不加水印。

- 每个模块中的每一个小知识点后都必须紧跟一句解析，统一写成“知识点｜一句话解析”；不能只在模块末尾写一条总解析。
- 解析优先说明原因、作用、影响、历史地位或易混辨析，不能只是换一种说法重复知识点。

## 唐朝海报成品提示词

```text
Use case: scientific-educational
Asset type: 中国历史课堂知识海报，标准 A4 竖版（210 × 297 mm），适合课堂投影与打印

Primary request:
设计一张主题为“唐朝·盛世气象与开放文明”的高质量中文历史课堂海报。画面像专业教辅信息图，学生能快速看懂唐朝从建立、鼎盛到衰亡的主线。

Scene/backdrop:
浅米色宣纸纹理背景，极淡的长安城坊市格局与祥云纹作底纹；边缘为克制的唐代宝相花装饰线。

Style/medium:
现代教辅信息图 + 克制的新中式；扁平矢量感；清晰卡片网格。标题为深色碑刻感中文字体，正文为清晰黑体。主色朱砂红，辅色黛青与米金，少量金黄色突出年份和考点。高对比、留白充足。

Composition/framing:
标准 A4 竖版。顶部为大标题、618—907 年时间轴和建立信息；中部上方为“贞观之治—武则天—开元盛世”三张并列人物卡；中部下方为“经济繁荣、民族关系、对外交往、灿烂文化”四区网格；底部为由盛转衰时间轴和总结解析。

Text (verbatim, render exactly; no extra text):
主标题：“唐朝”
副标题：“盛世气象与开放文明”
年代：“618—907 年”
建立：“618 年｜李渊（唐高祖）｜都城长安”

卡片一：“唐太宗｜贞观之治”
“吸取隋亡教训｜认识到百姓决定政权安危”
“虚心纳谏·重用人才｜魏征等帮助减少决策失误”
“三省六部制·完善科举｜提升治理与选才效率”
“轻徭薄赋·重视农业｜减轻负担并恢复生产”
“开明民族政策｜赢得各族拥戴”

卡片二：“武则天｜承前启后”
“中国唯一女皇帝｜突破古代帝位性别限制”
“打击敌对官僚｜巩固皇权与中央统治”
“创立殿试｜由皇帝亲自考查选拔人才”
“创设武举｜拓宽军事人才选拔渠道”
“重视农业｜稳定生产并为开元盛世蓄力”

卡片三：“唐玄宗｜开元盛世”
“整顿吏治｜提高官员办事效率与能力”
“裁减冗员｜减少官僚机构与财政负担”
“发展经济·改革税制｜充实国家财力”
“注重文教｜推动文化教育繁荣”
“国力达到鼎盛｜多项改革共同形成开元盛世”

模块：“经济繁荣”
“曲辕犁｜改进耕作方式，提高翻土效率”
“筒车｜利用水力灌溉，节省人力”

“唐三彩｜属于低温釉陶，反映开放风貌”
“长安坊市｜严整城市规划促进商业繁荣”

模块：“民族关系”
“开明民族政策｜尊重各族，减少民族隔阂”
“文成公主入藏｜带去技术，增进汉藏友好”
“松赞干布｜推动吐蕃经济文化发展”
“金城公主入藏·唐蕃会盟｜延续唐蕃友好交往”

模块：“对外交往”

“鉴真东渡｜向日本传播唐朝文化”

“玄奘西行｜赴天竺求取佛教经典”

模块：“灿烂文化”

“杜甫｜现实主义‘诗史’记录社会变迁”
“白居易｜语言通俗，诗歌关注现实生活”
“颜真卿·柳公权｜楷书端庄严谨，各具风格”
“吴道子｜绘画线条传神，被尊为‘画圣’”

底部时间轴：
“755—763 安史之乱｜使唐朝由盛转衰并形成藩镇割据”
“黄巢起义｜沉重打击唐朝统治”
“907 年朱温建立后梁｜唐朝灭亡，进入五代十国”
核心结论：“安史之乱：唐朝由盛转衰”
总结解析：“安史之乱是转折，黄巢起义重创统治，朱温建后梁终结唐朝。”

Historical reference images:
不使用扁平图标。将真实资料图片直接嵌入对应模块：
“经济繁荣”使用故宫博物院唐三彩骆驼文物照片；
“民族关系”使用布达拉宫历史建筑实景；
“对外交往”使用唐招提寺金堂实景；
“灿烂文化”使用李白课本常用写实画像。
图片统一裁切、加细边框和简短图注，不单独设置人物与文物资料图区。

Constraints:
- 所有中文逐字准确、简体中文、无乱码、无错别字、无多余文字。
- 正文字号足够大，课堂投影可读；每条知识独立成行。
- 人名、年代、史实与书名号必须准确。
- 不出现现代物件、西式纹章、日式元素；不使用照片拼贴、3D 字、霓虹色。
- 不加 logo，不加水印。
- 标题必须根据当前朝代生成：主标题为朝代名称，副标题概括该朝代最突出的历史特征；更换朝代后不得保留“唐朝”“盛世气象与开放文明”等旧标题。
```

生成其他朝代海报时，应同步替换为该朝代的博物馆藏品、历史遗址和公共领域人物画像，并在交付文件中保留图片来源。

## 替换检查清单

- 朝代名、起止年份、建立者、都城是否全部替换。
- 三个核心人物/阶段是否能串起“兴起—发展—鼎盛”。
- 经济、民族、外交、文化各保留 2—3 条最重要考点。
- 衰亡部分是否包含“转折事件—打击事件—灭亡事件”。
- 是否把易混淆知识做成对照或口诀。
- 简明版正文建议控制在 320 个汉字以内；知识扩展版建议控制在 450—600 个汉字。
- 每个模块至少包含“事实 + 作用/影响”，避免只有孤立名词。
