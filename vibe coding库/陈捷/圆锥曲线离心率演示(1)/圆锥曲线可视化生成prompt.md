# 圆锥曲线离心率可视化 · AI 生成 Prompt

> 用途：把本 prompt 发给任意 AI，可让它生成与当前可视化一致的模型。严格按现有功能描述，未新增任何内容。

---

【任务】生成一个单文件、自包含的中学数学可视化网页（HTML），主题：圆锥曲线的离心率 e。产物是一个 index.html，双击用浏览器打开即可使用；全部功能用原生 HTML/CSS/JS + Canvas 实现，不依赖任何外部 JS 库；允许引用 Noto Sans SC / Noto Serif SC 字体（在线 CDN，加载失败自动回退系统字体，不影响功能）。

【页面结构】
- 页眉：小字"V1 · V2 · V3 · V4 | 中学数学 · 解析几何"；大标题"离心率 e：圆锥曲线的统一钥匙"；副标题"拖动 e，看圆怎样被拉成椭圆、再裂成双曲线。四个视图，从全貌到细节。"
- 标题下方放一段"什么是偏心率 e？"解释：e = c/a（焦点离中心有多远 ÷ 半长轴）；e=0 是圆、0<e<1 是椭圆、e=1 是抛物线、e>1 是双曲线；一个 e 串起四类曲线，所以叫"统一钥匙"。
- 四个 Tab（#v1/#v2/#v3/#v4），hash 路由切换，当前 Tab 高亮。
- 每个视图：左侧画布卡片（Canvas）+ 右侧参数面板（固定约 300px，窄屏堆叠到下方）；画布下方是"课后小测"区。
- 底部页脚：一句话说明四个视图各自看什么。

【数学模型（必须一致）】
- 标准方程视角：曲线中心在原点，半长轴 a 归一化为 1，所有图形按同一大小缩放，方便对比形状。
- 参数关系：圆 e=0；椭圆 b=√(1−e²)、焦点(±e,0)、c=e；抛物线 y²=4x、焦点(1,0)、准线 x=−1；双曲线 b=√(e²−1)、渐近线 y=±bx、焦点(±e,0)。
- 画布纵向半幅 WORLD_Y=2.6（控制缩放）；画网格、坐标轴（带刻度数字）、中心点 O、顶点小黑点。
- 曲线采样：椭圆/圆 x=cos t、y=b·sin t；双曲线 x=±cosh u、y=b·sinh u（先画完右支所有点、再画左支，否则断线）；抛物线 x=t²、y=2t。
- 图上标注：焦点红点（椭圆/双曲线标 F₁/F₂，抛物线标 F）；双曲线画紫色虚线渐近线；抛物线画橙色虚线准线并标注"准线 x = −1"。

【四个视图】
1. V1 全局总览：e 滑块 [0, 1.414(√2)]，轨道渐变蓝→紫（70.7% 处用橙色竖线标记 e=1），刻度"0·圆 / 1·抛物线 / √2·等轴双曲线"；参数卡显示 a、b、c 与当前曲线方程（如 x² + y²/0.75 = 1）；预设按钮：圆 / 椭圆0.5 / 椭圆0.85 / 抛物线 / 双曲线1.2 / 等轴√2。
2. V2 椭圆段：e 滑块 [0, 0.98]；红点动点 P 沿椭圆运动，红色虚线连 F₁、F₂，面板实时显示 |PF₁|+|PF₂|（恒为 2）；"暂停动点/继续动点"按钮。
3. V3 抛物线分界点：e 滑块 [0.90, 1.10] 可跨过 1，50% 处橙色标记；"同屏对比 0.99/1.00/1.01"开关按钮，打开时同屏画三条曲线（蓝/橙/紫）及各自焦点并显示图例；预设 0.99/1.00/1.01。
4. V4 双曲线段：e 滑块 [1.01, 1.414]；在画布上从 x 轴到第一象限渐近线画橙色弧线并标注"θ = xx°"，面板实时显示 θ = arctan√(e²−1) 与两条渐近线夹角 2θ（e=√2 时 θ=45°，两渐近线互相垂直 = 等轴双曲线）；红点动点沿右支往返运动（参数 t=1.65·sin(phase)），红色虚线连 F₁、F₂，实时显示 |PF₁|−|PF₂|（恒为 2）；参数卡注明"双曲线 c²=a²+b²，椭圆 c²=a²−b²"；预设 1.05/1.2/等轴√2。

【面板组件】每个视图都有：滑块卡（e 标签 + 当前值大字号读数 + 曲线类型小字 + 轨道渐变 + 刻度）、实时参数卡（a/b/c 三格，标签用"半长轴 a""焦距 c"等人话）、快捷定位预设按钮卡。

【名词小词典】每个视图一张可折叠卡（用 <details>，标题"名词小词典"+"点击展开"），只解释本视图出现的符号；条目标题格式统一为"专有名词+变量"（如"离心率 e""半长轴 a""焦距 c""焦点 F₁、F₂""张角 θ"），没有变量的直接写专有名词（如"焦点""顶点""准线""渐近线""等轴双曲线"），定义式写"椭圆定义 |PF₁|+|PF₂| = 2a"这种；描述一律用学生能听懂的口语。

【课后小测】每个视图画布下方，标题"课后小测"；题目用 1、2、3、4 编号（不标难度）；每题下方一个折叠的"查看推导"（<details>），展开后是完整推导/答案；凡能用可视化验证的题，推导末尾加一行橙色"可视化：……"的操作指导（例如"把滑块拖到 0.02 和 0.97 对比两个椭圆的形状""点暂停动点把 P 停在最右端读两条红虚线的长度""点同屏对比看三条曲线"），告诉学生怎么操作可视化来验证答案。

【文案风格】面向高中生的口语化中文，去术语、符号后配人话，禁用 emoji。

【配色】纸感米白背景 #F6F3EC、深墨文字 #24272C、次要文字灰 #6C675D；曲线颜色：圆/椭圆蓝 #2E5E8C、抛物线橙 #C4551E、双曲线紫 #6B4E8C；焦点与动点红 #C43E3E、中心灰 #8A8476；e=1 分界用橙色竖线标记。

【交互与响应式】滑块用 22px 圆形 thumb；动画用 requestAnimationFrame 且提供暂停/继续；断点 820px 以下单列堆叠；触控目标不小于 44×44px；页面初始静态状态即可读懂主结论，核心信息不依赖交互。
