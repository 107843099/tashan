离心率 e：圆锥曲线的统一钥匙

拖动 e，看圆怎样被拉成椭圆、再裂成双曲线。四个视图，从全貌到细节。

什么是偏心率 e？ 偏心率（也叫离心率）e 是衡量圆锥曲线"扁平或开口程度"的一个数，定义为 e = c/a——也就是"焦点离中心有多远，除以半长轴"。e = 0 是圆，0 < e < 1 是椭圆，e = 1 是抛物线，e > 1 是双曲线。一个 e 就能把四类曲线串起来，所以叫"统一钥匙"。

课后小测
1.判断以下 e 值分别对应哪种曲线：e = 0、e = 0.7、e = 1、e = 1.4。
查看推导
e = 0 是圆；0 < e < 1 是椭圆（0.7）；e = 1 是抛物线；e > 1 是双曲线（1.4）。可视化：把滑块分别拖到这四个值，看曲线颜色和形状变化。
2.已知某圆锥曲线长轴 2a = 10，两焦点距离 2c = 6，求 e，并判断它是什么曲线。
查看推导
a = 5，c = 3，e = c/a = 3/5 = 0.6。因为 0 < e < 1，所以是椭圆。
3.用你自己的话解释：为什么 e 越大，椭圆越扁、双曲线越开？e = 1 为什么是分界线？
查看推导
e = c/a，e 越大说明焦点离中心越远：椭圆里焦点分得越开，曲线被拉得越扁；e > 1 时 b = √(1−e²) 变成负数开不了方，必须换成 b = √(e²−1)，公式的"断裂"对应图形"裂开"成双曲线。e = 1 正好是两种 b 的公式交接处，所以是分界线。可视化：把滑块从 0 一直拖到 √2，重点看 e 跨过 1 的瞬间。
4.地球轨道 e ≈ 0.017，哈雷彗星 e ≈ 0.967。谁的轨道更接近圆？哪个更"拉长"？为什么？
查看推导
e 越接近 0 越接近圆。地球 e = 0.017 非常接近 0，轨道几乎是圆；哈雷彗星 e = 0.967 接近 1，椭圆被拉得极扁。可视化：把 e 分别设为 0.02 和 0.97，对比两个椭圆的形状。

课后小测
1.椭圆上一点 P 到两焦点距离之和为 10，求 2a 和 a。
查看推导
椭圆定义：|PF₁| + |PF₂| = 2a。所以 2a = 10，a = 5。
2.已知 e = 0.6、a = 5，求 c、b，并写出椭圆的标准方程。
查看推导
c = ae = 5 × 0.6 = 3；b = √(a²−c²) = √(25−9) = 4；标准方程 x²/25 + y²/16 = 1。
3.从"焦点分离"和"b = √(1−e²)"两个角度，分别解释 e 变大时椭圆为什么变扁。
查看推导
角度一：e 大 → c 大 → 两个焦点离中心越远、分得越开 → 椭圆被拉扁。角度二：e 大 → 1−e² 小 → b 小 → 短轴变短 → 椭圆变"瘦"。可视化：拖动 e，同时观察面板里 b 的读数和画布上两个红色焦点的位置。
4.动点 P 运动到椭圆最右端时，|PF₁| 和 |PF₂| 分别是多少？（提示：最右端点坐标为 (a, 0)，两焦点在 (−c, 0) 和 (c, 0)）
查看推导
最右端点 (a, 0) 到左焦点 F₁(−c,0) 的距离 = a + c；到右焦点 F₂(c,0) 的距离 = a − c。两者之和 = 2a，符合椭圆定义。可视化：点"暂停动点"，把 P 停在最右端，读两条红虚线的长度。

e = 1.00 · 抛物线 拖动 e 跨过 1，看曲线如何从闭合变开口
课后小测
1.抛物线 y² = 4x 的焦点坐标和准线方程分别是什么？
查看推导
标准形式 y² = 4px，对比得 4p = 4 → p = 1。焦点 (p, 0) = (1, 0)，准线 x = −p = −1。
2.e 从 0.99 变到 1.01 时，曲线经历了"闭合 → 开口 → 分叉"。请解释为什么 e 刚超过 1，曲线就"裂"成两支？
查看推导
e < 1 时 b = √(1−e²) 是实数，椭圆闭合；e = 1 时 b = 0，退化成开口的抛物线；e > 1 时 1−e² < 0，b 必须换成 √(e²−1)，方程变成双曲线，图形自然分成两支。可视化：点"同屏对比 0.99 / 1.00 / 1.01"，三条曲线并排看。
3.任取抛物线 y² = 4x 上一点 (1, 2)，验证它到焦点 (1, 0) 的距离等于到准线 x = −1 的距离。
查看推导
到焦点距离 = √((1−1)² + (2−0)²) = 2；到准线距离 = |1 − (−1)| = 2。两者相等 ✓，这正是抛物线的定义。可视化：在 V3 画布上数格子，(1,2) 到焦点和准线都是 2 格。

e = 1.20 · 双曲线 橙色弧 = 渐近线与 x 轴的张角 θ
课后小测
1.对双曲线 x² − y² = 1，求 a、b、c、e 和渐近线方程，并判断它是不是等轴双曲线。
查看推导
a² = 1, b² = 1 → a = b = 1；c² = a² + b² = 2 → c = √2；e = c/a = √2；渐近线 y = ±(b/a)x = ±x。因为 a = b，所以是等轴双曲线。
2.为什么"等轴双曲线"叫"等轴"？它的两条渐近线夹角是多少？
查看推导
"等轴"指实轴和虚轴等长，即 a = b。此时渐近线倾角 θ = arctan(b/a) = arctan(1) = 45°，两条渐近线夹角 2θ = 90°，正好互相垂直。可视化：把 e 拖到 √2，看橙色张角 θ 显示 45°。
3.已知双曲线满足 c² = a² + b²，请据此说明为什么双曲线的 e 一定大于 1。
查看推导
c² = a² + b² > a²（因为 b² > 0），所以 c > a，于是 e = c/a > 1。这就是双曲线天然落在 e > 1 区间的原因。
4.双曲线"永远碰不到"渐近线，但 e 越大时它又"贴得越近"。结合张角 θ 的变化，说说你从可视化里看到了什么。
查看推导
双曲线上任意点满足 y²/b² = x²/a² − 1 < x²/a²，所以 |y| < (b/a)|x|，即曲线始终在渐近线 y = ±(b/a)x 的内侧，永远不相交；x 越大两者越接近。e 越大 b 越大，渐近线越陡（θ 越大），曲线张开得越开。可视化：拖动 e 从 1.01 到 √2，看紫色曲线如何贴着渐近线跑、橙色张角如何变大。
