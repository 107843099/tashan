## 1. 一次性完整重建 Prompt

如果希望用一个 Prompt 从零重建当前版本，可直接使用下面的内容。

```text
请制作一个面向中学有机化学课堂的中文交互式教学网页，主题为“甲烷与氯气的光照取代反应”，并加入取代反应判断训练与 ATP 能量释放剧场。

一、项目形式
1. 使用原生 HTML、CSS、JavaScript 和 WebGL 实现，不依赖外部 CDN 或第三方运行时。
2. 页面必须可以完全离线运行，最终打包成单个 index.html，双击即可在 Chrome、Edge 或 Firefox 中打开。
3. 同时保留便于维护的开发源文件：
   - dev/shell.html：HTML 骨架；
   - dev/style.css：页面样式；
   - dev/reacts.js：反应方程式、原子、关键帧、化学键和字幕数据；
   - dev/main.js：WebGL 渲染器和交互逻辑；
   - dev/build.ps1：把上述文件合并为根目录及 dist 目录中的 index.html。
4. 页面使用中文，适合课堂投影、教师讲解和学生自主观察。

二、主界面
1. 标题为“甲烷与氯气 · 3D 微观反应实验室”。
2. 副标题说明页面聚焦光照取代反应，帮助学生观察断键、成键与原子守恒。
3. 顶部提供“能量释放（以 ATP 为例）”按钮。
4. 不要显示“有机化学构建平台”或“有机结构构建台”按钮。
5. 显示原子颜色图例：
   - 碳 C：黑色；
   - 氢 H：浅灰；
   - 氧 O：红色；
   - 氯 Cl：绿色；
   - 溴 Br：棕色；
   - 铜 Cu：黄铜色。
6. 主体采用左侧知识与方程式、右侧 3D 动画的双栏布局；窄屏时改为单栏。

三、取代反应知识区
1. 展示反应方程式：CH₄ + Cl₂ → CH₃Cl + HCl，并清楚标注“光照”条件。
2. 给出定义：有机物分子中的原子或原子团被其他原子或原子团替代的反应，叫取代反应。
3. 说明甲烷氯代可继续生成 CH₂Cl₂、CHCl₃ 和 CCl₄，但当前动画只演示第一步。
4. 说明动画展示的是断键、半键转向和重新成键的净变化；实际反应属于自由基链式取代。
5. 显示反应前后总原子数，强调每个原子一一对应、不增不减，体现原子守恒。

四、取代反应判断教学
1. 新增“判断方法”模块，核心表述为：看“谁被谁换走”，不要只看是否生成两种产物。
2. 展示取代反应通式：R—A + B—X → R—B + A—X。
3. 给出三步判断法：
   - 比较反应前后有机物的碳骨架；
   - 判断原来的原子或原子团是否离开，并在同一位置接入新的原子或原子团；
   - 排除加成反应和消去反应。
4. 至少展示以下三个拓展示例：
   - 乙烷卤代：C₂H₆ + Cl₂ → C₂H₅Cl + HCl，H 被 Cl 替换；
   - 溴乙烷水解：C₂H₅Br + NaOH → C₂H₅OH + NaBr，Br 被 OH 替换；
   - 苯的溴代：C₆H₆ + Br₂ → C₆H₅Br + HBr，苯环上的 H 被 Br 替换。
5. 增加三题即时判断练习。每题显示一个有机反应方程式，提供“是取代反应”和“不是取代反应”两个按钮。
6. 学生作答后立刻显示正误与原因，并更新得分；答题前只给提示，不提前显示答案。
7. 题目至少覆盖卤代烃水解、烯烃加成和酯化反应，以帮助学生建立判断边界。
8. 完成三题后可以重新练习。

五、3D 微观反应动画
1. 使用 WebGL 绘制不透明的球棍模型，正确启用深度遮挡，避免原子透视和化学键穿模。
2. 3D 画布使用浅蓝色背景，化学键使用白色，适合课堂投影和录屏。
3. 甲烷和氯气的每一个原子在动画前后必须保持唯一身份和一一对应关系。
4. 反应过程分为四个关键阶段：
   - C—H 与 Cl—Cl 键从中间断开，两端保留半键；
   - 断键后的半键保留在各自原子上；
   - 半键随原子移动并转向新的连接方向；
   - C—Cl 与 H—Cl 半键在中间对接，形成 CH₃Cl 和 HCl。
5. 化学键不能凭空瞬间消失或出现；断裂时从中央分开，成键时从两端逐渐合拢。
6. 页面提供播放、暂停、重置、进度拖动、速度选择、自动旋转、鼠标拖动旋转、滚轮缩放和缩放滑块。
7. 在画布上显示当前反应阶段、步骤字幕、反应名称和反应条件。
8. 鼠标指向原子时显示元素名称。
9. WebGL 不可用或运行出错时，显示明确的中文错误信息。

六、ATP 能量释放剧场
1. 点击顶部“能量释放（以 ATP 为例）”后进入独立的深色教学剧场。
2. 标题为“ATP 怎样为细胞释放可用能量？”。
3. 页面先提示学生观察最外侧磷酸基团的变化，不要一开始就展示完整讲解。
4. 动画以示意模型展示 ATP 由腺苷和三个磷酸基团组成，水分子靠近后，最外侧磷酸基团分离，形成 ADP 和无机磷酸 Pi。
5. 动画分步显示：
   - 水分子靠近 ATP；
   - 最外侧磷酸基团分离；
   - 出现 ADP、Pi 和能量释放效果；
   - 显示方程式 ATP + H₂O → ADP + Pi。
6. 提供“播放”和“重复播放”按钮；重复播放时必须清除上次动画状态和计时器，从头播放。
7. 动画结束后才显示“下一步：查看讲解”按钮。
8. 只有学生点击“下一步”后，才显示完整文字讲解；不要在动画结束时自动出现答案。
9. 讲解内容应准确说明：
   - ATP 水解生成 ADP 和 Pi；
   - 产物及其与水的相互作用更稳定，体系自由能降低；
   - 释放的自由能可与肌肉收缩、主动运输和物质合成等吸能过程偶联；
   - “高能磷酸键”不是断裂时直接释放能量，断键本身需要能量，整个反应的净能量变化才表现为释放。
10. 提供“返回甲烷取代反应”按钮。

七、视觉与可用性
1. 主教学页采用白色卡片、浅蓝画布和蓝色强调色，信息清楚、克制，适合学校课堂。
2. ATP 剧场采用深蓝绿色背景、青色和金黄色能量强调色，与主页面形成明显模式切换。
3. 控件必须具有 hover、disabled 和反馈状态。
4. 所有按钮使用 button 元素并设置 type="button"，重要动态反馈使用 aria-live。
5. 页面需要适配桌面和移动端，移动端不得出现明显横向溢出。

八、构建与验证
1. 生成开发源码后运行 dev/build.ps1，确保根目录 index.html 与 dist/index.html 内容一致。
2. 对 dev/main.js 和 dev/reacts.js 运行 JavaScript 语法检查。
3. 检查最终页面中不再出现“有机结构构建台”“核裂变”“一颗中子”等旧内容。
4. 检查“能量释放（以 ATP 为例）”“重复播放”“下一步：查看讲解”和取代反应判断练习均已写入最终 dist/index.html。
5. 用本地静态服务器验证首页返回成功状态。
6. 保留现有功能，不引入不必要依赖。
```

## 9. 质量检查 Prompt

```text
请检查这个离线 3D 化学教学网页，并只报告可以复现的问题。

检查范围：
1. 化学准确性：方程式、原子守恒、取代反应定义、反应分类、ATP 水解解释。

6. 无障碍：按钮语义、键盘操作、焦点状态、aria-live、文字对比度和减少动画偏好。
7. 离线性：断网后是否仍可完整加载，不得请求外部脚本、字体、图片或接口。
8. 构建一致性：dev 源文件生成的根目录 index.html 与 dist/index.html 是否一致。

输出格式：
- 按严重程度列出问题；
- 每个问题包含位置、复现步骤、预期结果、实际结果和建议修复；
- 如果某项未发现问题，明确写“未发现可复现问题”。
```
