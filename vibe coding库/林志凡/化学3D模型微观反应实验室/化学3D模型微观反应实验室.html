    判断方法

    看“谁被谁换走”，不要只看是否有两种产物

    取代反应的核心是：有机物中的一个原子或原子团，被另一个原子或原子团替换。碳骨架通常保留，被换下来的部分常与另一反应物结合。

    R—A＋B—X→R—B＋A—X
    1. 圈有机物：比较反应前后的碳骨架。
    2. 找变化：原来的 A 离开，同一位置接上 B。
    3. 排除：若双键变单键并接入两个原子，通常是加成；若脱去小分子并生成双键，通常是消去。
    乙烷卤代C₂H₆ + Cl₂ → C₂H₅Cl + HClH 被 Cl 替换
    溴乙烷水解C₂H₅Br + NaOH → C₂H₅OH + NaBrBr 被 OH 替换
    苯的溴代C₆H₆ + Br₂ → C₆H₅Br + HBr苯环上的 H 被 Br 替换
    轮到你判断0 / 3

    讲解

    ATP 水解为什么能为细胞供能？

    ATP 与水反应，生成 ADP 和无机磷酸（Pi）：ATP + H₂O → ADP + Pi + 能量。水解后形成的新化学键和产物与周围水分子的相互作用更稳定，使体系的自由能降低。释放出的能量可与肌肉收缩、主动运输和物质合成等吸能过程偶联。“高能磷酸键”不是断裂时直接放能；断键本身需要能量，整个反应的净能量变化才是释放。
