# AI辅助PBL课程设计

## 提示词与使用说明 V1.1

> 从一个教学主题出发，逐步形成有真实问题、有学习目标、有探究过程、有评价依据的PBL课程初稿。

## 一、项目介绍

这是一套面向教师的AI辅助PBL（项目式学习）课程设计工作流，包含基础信息表、6个递进式Prompt模板、教师检查要点和复用记录模板。

教师提供学生情况、教学目标和实施条件，AI协助整理主题、提出备选方案、搭建探究路径及教学材料。教师在关键节点作出选择，并根据学生的真实表现继续调整。

**本工具的目标，是帮助教师更快形成可审核、可试教、可改进的课程方案。AI生成的方案不等于已经通过课堂验证的课程。**

### 1. 适合谁使用

- 希望开展PBL，但需要课程设计支持的教师。
- 已有教学主题，希望加入真实探究、跨学科连接或学生自主决策的教师。
- 希望将已有项目迁移到其他年级、学科或教学场景的教师。

模板可用于幼儿园、小学、初中和高中阶段的设计尝试。实际适用范围应依据具体案例和试教记录标注，不能仅凭AI可以生成内容就宣称全学段有效。

### 2. 可以得到什么

- 主题探究价值与可行方向。
- 适配学生经验和能力的学习目标。
- 驱动性问题及学生可选择的研究方向。
- 分课时探究路径、教师引导和学习证据。
- 最终成果、展示方式和简明评价工具。
- 可选的课程海报文案、版式或图片生成指令。

### 3. 使用条件

核心流程需要支持多轮对话的文本AI工具；海报图片需要额外的图像生成或排版能力。具体功能与费用以教师所用工具为准，不绑定某一品牌。

建议在同一对话中分步使用。更换工具或开启新对话时，应同时粘贴基础信息和已经确认的设计摘要，不能只粘贴“请根据以上内容”。

## 二、课程设计原则

### 1. 让真实问题带动学习

先明确学生要理解或改善什么，再安排活动。调查、阅读、实验、制作和展示，都应帮助学生回应同一个核心问题。

### 2. 将学习目标、探究活动和评价依据对应起来

每个主要目标都应有学生实际完成的任务，以及可供教师判断学习情况的证据。例如，“根据比较结果解释材料选择”，可以对应材料测试、记录表和学生的口头说明。

### 3. 给学生保留有意义的选择

教师可以设定课时、材料和安全边界，同时让学生参与选择研究问题、测试方法、设计方案或表达方式。AI不应提前规定所有学生必须得出相同答案、做出相同作品。

### 4. 根据实际能力调整支持

年龄和年级是参考，还应考虑阅读表达、测量记录、工具操作、合作经验及特殊支持需要。同龄学生也可能需要不同的任务支持。

### 5. 将反馈与修改放入探究过程

观察、提问、探究、创造、反思是一种便于组织的路径，允许往返。例如，模型测试失败后可以重新观察、提出新问题，再修改方案。

### 6. 让成果说明学习发生了什么

成果可以是模型、报告、建议、讲解、行动或设计方案。教师需要看到学生如何提出问题、收集证据、作出选择和修改想法。

本工作流在学习目标、持续探究、真实性、学生选择、反思、反馈修改和对外展示等方面参考了[PBLWorks的项目设计要素](https://www.pblworks.org/what-is-pbl/gold-standard-project-design)。本文件的六步提示词及Observe → Wonder → Explore → Create → Reflect组织方式，是为工具使用而设计的工作流程，并非该机构的官方六步模型，也不是PBL唯一的实施顺序。

## 三、开始前：填写基础信息

先填写以下内容，再发送总指令和各步骤提示词。标为“选填”的内容可以暂时留空；课程资源和学生情况越具体，方案通常越容易评估是否可行。

```text
【课程主题】：
【学生年龄与年级】：
【总课时与每课时长度】：
【最希望学生学会的内容或能力】：
【可用场地、材料与设备】：

【地区与课程背景，选填】：如内地小学、香港小学；如需对齐课程标准，请提供具体文件或条目。
【班级人数与分组方式，选填】：
【学生已有经验，选填】：包括相关知识、阅读表达、测量、工具操作和合作经验。
【主要学科与希望连接的学科，选填】：
【预算与准备时间，选填】：
【学习支持需要，选填】：使用概括描述，不填写学生姓名、诊断报告等个人资料。
【特殊限制，选填】：如不能外出、不能使用明火、不能要求家长购买材料。
【成果受众，选填】：如其他班级、家长、学校工作人员或社区成员。
【输出语言，选填】：简体中文／繁体中文／英文／其他。
```

### 总指令：每次启动工作流时先发送

```text
你是一名协助教师开展PBL课程设计的教研伙伴。请依据我提供的基础信息，帮助我逐步形成可审核、可试教的课程方案。

请遵守以下规则：
1. 默认采用分步协作模式，每次只完成我指定的步骤，不提前生成全部课程。
2. 围绕学生需要理解的问题组织课程，并将学习目标、探究任务和评价依据相互对应。
3. 保留学生提出问题、选择方法、表达不同观点和修改方案的空间。
4. 以实际课时、材料、预算和学生能力为边界。每次新增活动，都要考虑是否有时间完成。
5. 基础信息中若缺少会显著影响设计的内容，先集中询问最多3个关键问题；其他信息可列为“暂定假设”，等待教师修改。涉及活动安全的关键条件不明时，先提出条件明确的替代方案。
6. 区分教师已提供的信息、你的设计建议和需要核实的事实。不要编造学生反馈、试教效果、研究结论或课程标准条目。
7. 需要引用科学知识、地方资料或课程标准时，提供可以核查的来源；无法核实则标注“待教师核实”，不要假称已查证。
8. 这是教师备课工具，默认不要求学生注册或直接使用AI。若建议学生使用AI，说明用途，并保留学生自己观察、推理和决策的任务。
9. 输出使用清晰、具体的教师工作语言，避免只写“提升核心素养”等无法观察的表述。
10. 每一步最后给出：本步结果、需要教师决定的1—3项内容，以及可复制的“已确认设计摘要”。尚未确认的内容须标为待选或暂定。

以下是课程基础信息：
【粘贴已填写的基础信息】
```

## 四、6个递进式Prompt模板

### 第一步：主题研究 Research

**目的：** 找到学生值得持续探究、且在现有条件下能够推进的问题。

```text
请完成第一步：主题研究。先不要编写完整课程。

依据我的基础信息，提出3—5个有探究价值的方向。每个方向说明：
1. 与学生生活、兴趣或真实环境的联系。
2. 可以研究的具体问题，以及目前需要进一步了解的内容。
3. 学生可以通过观察、比较、实验、访谈、阅读或设计测试获得哪些证据。
4. 最相关的1—3个学科连接，以及这些知识如何帮助解决问题。不要为了跨学科而强行加入所有学科。
5. 可能形成的成果及其受众，仅作初步设想。
6. 所需条件、主要困难，以及简化办法。

区分“查资料即可获得基本答案的知识问题”和“需要继续收集证据、作出判断或迭代设计的探究问题”。资料查询可以是探究的一部分。

最后推荐1—2个最符合条件的方向，说明理由，并请我选择或修改后再进入下一步。
```

**教师检查：** 学生能实际调查或尝试吗？问题与他们有关吗？跨学科知识是否真的派得上用场？

### 第二步：学情适配与学习目标 Differentiate

**目的：** 明确这批学生适合学什么、需要什么支持，以及怎样看出他们学会了。

```text
请完成第二步：学情适配与学习目标。

我选择的主题探究方向是：【填写】。

请先围绕本班学生设计，不要默认输出从幼儿园到高中的所有版本。仅在我明确要求跨年龄比较时，再给出指定年龄段的对照。

请输出：
1. 学生可能已有的相关经验、需要确认的前置能力，以及2—3个简短的课前了解方法。不要将推测当作本班事实。
2. 3—4个具体、可观察的核心学习目标，优先使用“比较、记录、解释、根据证据选择、测试并修改”等表述。
3. 按“学习目标—学生任务—学习证据”列出对应关系。
4. 同一核心目标下的支持方案：需要更多帮助的学生如何参与；大部分学生完成什么；有余力的学生可以怎样深入。不要给学生固定贴标签。
5. 适合学生的观察、理解、调查和创造任务，以及需要教师示范或协助的环节。
6. 最容易超出当前条件的要求，以及可以删减或替代的做法。

如我提供了课程标准，请说明具体对应关系；没有文件时，只提出一般教学目标，不宣称已经对齐某个地区的课程标准。

请让我确认核心学习目标和任务难度后再继续。
```

**教师检查：** 目标是否过多？学生能用自己的行动或表达展示理解吗？任务会不会主要由教师或家长完成？

### 第三步：驱动性问题 Driving Question

**目的：** 用一个清楚、有挑战且可以推进的问题串起项目。

```text
请完成第三步：驱动性问题设计。

基于已确认的主题方向、学生情况和核心目标，设计3—5个候选驱动性问题。

问题需要：
- 学生听得懂，并能看出与自己或真实受众的联系。
- 有探究和决策空间，不预设唯一作品或统一答案。
- 需要学生收集、比较或应用证据，不能只凭一次资料搜索或AI回答完成项目。
- 在现有课时和资源内能够取得有意义的进展。

请用表格列出：候选问题、核心学习目标、主要探究行动、可能成果与受众、可行性及局限。

推荐1个最适合当前条件的问题，并补充：
1. 一个适合课堂导入的情境。假设情境必须明确标注，不得编造真实学校事件。
2. 3—5个供教师参考的子问题，注明应允许学生补充或替换。
3. 学生可以自主选择的至少2个方面。
4. 初步成果设想和2—3条成功标准，供下一步规划使用，尚不固定最终作品形式。

请等待我确认驱动性问题，再设计探究路径。
```

**教师检查：** 学生需要研究和判断什么？不同小组是否可能提出不同但有证据支持的方案？

### 第四步：探究路径与课时安排 Inquiry

**目的：** 将问题转化为前后相连、时间可控的学习过程。

```text
请完成第四步：探究路径与课时安排。

已确认的驱动性问题是：【填写】。

请以Observe（观察）→ Wonder（提问）→ Explore（探究）→ Create（创造）→ Reflect（反思）组织路径。阶段可以跨课时，也可以往返；不要把它机械理解成五节课。

先说明每个阶段如何为下一阶段提供问题、证据或设计依据，再按照实际课时列出：
- 所属阶段、课时与预计分钟数。
- 对应学习目标。
- 学生具体做什么，以及可以作出哪些选择。
- 教师如何引导，给出1—2句可直接使用的提问。
- 必要的知识或技能小教学，以及安排它的原因。
- 所需材料、课前准备和分组安排。
- 需要保留的学习证据，以及教师如何据此调整下一步。
- 可能困难与简化方案。

必须包含：
1. 至少一次收集证据并据此解释或选择的任务。
2. 至少一次获得反馈后修改想法、作品或方案的机会。
3. 与成果受众交流或展示的安排；如果暂时无法接触预期受众，说明可先试用的替代方式及其局限。
4. 适合年龄的个人反思，使教师能了解每个学生的学习。

请核对全部活动是否能放入已给定课时，计入材料分发、整理、分享和修改时间。额外需要的课外时间必须单独说明，不能默认学生或家长承担。

课时不足时，请明确建议删减范围或增加课时；若只能完成项目中的一个片段，应如实标注为“PBL导入或微型探究活动”。
```

**教师检查：** 每个活动如何回应驱动性问题？是否给学生留下思考、失败和修改的时间？总时长是否成立？

### 第五步：成果与评价 Product & Assessment

**目的：** 明确学生最终展示什么，以及如何依据过程和成果判断学习。

```text
请完成第五步：成果与评价，并检查它与第四步是否一致。

基于已确认的驱动性问题、目标和探究路径，细化一个主要成果方案。必要时提供一个材料要求更低、能展示相同核心学习的替代方案，不要额外叠加大量作品。

请说明：
1. 成果是什么，为谁提供信息、解释或帮助，怎样回应驱动性问题。
2. 学生可以自己完成的部分、教师提供的支持，以及不应由成人代做的核心判断。
3. 需要呈现哪些过程证据，如问题记录、测试数据、设计草图、选择理由或修改前后的比较；只保留有判断价值的材料。
4. 展示方式、受众如何反馈，以及学生如何使用反馈。
5. 如需调整第四步的活动或时间，请列出具体修改，检查总课时是否仍然成立。

请同时生成：
A. 学生版成功标准：3—4条，使用相应年龄能理解的语言。
B. 教师简明评价表：围绕已确认目标设置3—4个维度，每个维度用“需要支持／基本达到／表现充分”描述可观察行为，并指出对应证据。
C. 学生自评或同伴反馈：3个简短问题，其中至少1个追问“你根据什么这样判断”，至少1个引导提出具体修改建议。

评价应覆盖知识理解和探究过程，不以美观、材料价格或展示口才代替学习判断。对小组项目，加入简短的个人说明或教师观察，避免将小组作品等同于每个学生的学习水平。

最后汇总一份可独立阅读的教师实施稿：基础信息、驱动性问题、学习目标、课时计划、材料准备、成果与评价、必要的活动注意事项、待核实内容。

只汇总已经确认的内容；新增加的建议应单列并标为待确认。
```

**教师检查：** 作品能否说明学生为什么这样做？评价是否和前面目标一致？能否看出个人学习情况？

### 第六步：可视化呈现 Visualize（可选）

**目的：** 将已经确认的方案转化为便于学生理解的项目展示板或海报。

课程实施稿在第五步已经形成。不需要海报时，可以直接进入试教。教师制作的课程海报也不等于学生的最终学习成果。

```text
请完成第六步：可视化呈现。只使用已经确认的课程内容，不新增学习目标、活动、成果或未经证实的课堂效果。

我选择的输出模式是：【A 海报文案与版式／B 可直接用于图像工具的提示词／C 生成海报图片】。
输出语言是：【填写；默认简体中文】。

请制作适合3:4竖版的PBL项目展示板，视觉风格为手绘、自然、具有学生探究感，像课堂中的project board。根据学生年龄调整插画和字体风格，初高中版避免过度幼儿化。

内容包括：
1. 项目名称 Project Title。
2. 驱动性问题 Driving Question。
3. 3—4个关键探究问题 Key Inquiry Questions。
4. Observe / Wonder / Explore / Create / Reflect五个阶段，每阶段只放一句关键任务；可用回箭头体现测试和修改。
5. 最终成果 Final Product及成果受众。
6. 一个适合课堂继续填写的“我们的新发现／我们还想研究”区域。

先压缩文字，再安排视觉层级。使用简单插画、箭头、便签和标签辅助理解，保留足够留白，不把完整教案塞进图片。中文为主时可只保留必要英文标签，无需全文中英重复。

A模式：输出可编辑文案和分区排版说明。
B模式：输出适合图像生成工具使用的完整提示词，同时附上可以人工排版的准确文字清单。
C模式：仅在当前工具具备图像生成功能时生成图片，同时提供准确文字清单。若当前工具不能生成图片，请明确说明并改为B模式，不要声称图片已经生成。

不得生成冒充真实课堂记录的学生照片、引语或试教成果。图中如使用示意作品，应标明“示意”。文字较多或无法清晰准确呈现时，优先建议保留插画背景并通过排版工具添加文字。
```

**教师检查：** 字是否清楚、准确？海报是否和课程一致？是否为课堂中的学生发现保留空间？

## 五、具体使用方式

### 1. 分步协作：适合首次设计或需要认真打磨的课程

1. 填写基础信息，发送总指令。
2. 发送第一步提示词，选择探究方向。
3. 发送第二步提示词，确认学习目标和支持方式。
4. 发送第三步提示词，确定驱动性问题和初步成果。
5. 发送第四步提示词，核对活动、材料和总课时。
6. 发送第五步提示词，完善成果、评价和教师实施稿。
7. 按需使用第六步生成海报内容。
8. 教师核实内容并试教，记录实际效果，再修改方案。

每一步都可以要求AI调整。推荐使用“指出问题＋明确限制＋保留内容”的方式：

```text
第四步的制作任务偏多。请在保留“根据测试证据解释选择”这一目标的前提下，将制作活动减少为一个，并把总时间控制在4课时、每课时40分钟。请说明删减了什么，并重新核对展示和修改的时间。
```

### 2. 一次生成：适合快速比较方向

将基础信息、总指令和6个模板放入同一条消息，并在最后加入以下指令：

```text
本次切换为“一次生成初稿”模式，覆盖总指令中逐步等待确认的要求。

请按六步顺序生成一份供教师审阅的初稿。关键缺项先集中询问最多3个问题；其余假设明确列出。自动选择的探究方向、目标和驱动性问题均标为“暂定”，不得写成教师已确认。

第五步输出完整教师实施稿；第六步仅输出海报文案，不自动生成图片。最后列出最需要教师复核的3个决策。一次生成结果需要教师审阅后才能进入试教。
```

### 3. 迁移已有课程：适合平台复用与再创作

```text
以下是一份已有PBL方案：【粘贴原方案】。
新的教学条件是：【粘贴新的基础信息】。

请先分析再修改：
1. 原方案最值得保留的学习目标、探究方法和关键设计判断是什么？
2. 哪些部分依赖原有年龄、课时、地区、资源或学生经验？
3. 迁移到新条件后，哪些可以保留、哪些必须调整、哪些尚不能确定？请说明理由。

请列出“原设计—新设计—修改理由—需要重新验证的内容”。待我确认后，再改写受影响的步骤，并同步检查目标、活动、成果与评价是否一致。

保留原项目名称、作者和来源信息；不清楚的授权情况标为待确认。原项目已有的课堂效果不能直接当作新方案的验证结果。
```

### 4. 根据试教记录改进

```text
以下是原课程方案：【粘贴】。
以下是去标识化的试教记录：【学生表现、时间使用、实际困难、代表性证据和教师判断】。

请分开整理已观察到的事实和可能解释，不补写不存在的学生表现。
围绕核心学习目标，指出最多3个优先改进点，并提出具体修改。
每项修改说明：依据是什么、调整哪个环节、需要多少额外资源、下次通过什么证据判断是否改善。
缺少证据时标注“尚不能判断”，不要根据作品完成或学生表示喜欢就断言学习目标全部达成。
```

## 六、简短示例：让教师看懂这套流程

> 以下为设计示例，未经过课堂试教，不代表已验证的教学效果。

### 1. 输入条件

| 项目 | 示例内容 |
| --- | --- |
| 主题 | 纸桥与结构 |
| 学生 | 小学四年级；具体测量、记录能力需课前了解 |
| 课时 | 4课时，每课时40分钟 |
| 班级 | 24人，6组，每组4人 |
| 目标 | 比较不同纸桥结构的表现，依据公平测试结果解释选择，并修改设计 |
| 材料 | 相同规格A4纸、尺子、相同的小积木、稳定支撑物、记录纸 |
| 限制 | 不要求家庭购买材料；低位桌面操作，限制载荷，手脚不伸入受力结构下方 |
| 成果受众 | 受邀参观的另一班同学；如不能邀请，先进行班内试展示 |

### 2. 六步输出示意

| 步骤 | 示例内容 |
| --- | --- |
| 主题研究 | 探究改变纸的形状是否影响跨越同一间距时的承重表现，连接科学探究、数学记录与工程设计 |
| 学情与目标 | 学生能在纸张、桥面跨度、积木规格和放置位置一致的条件下进行比较，并根据测试记录解释方案选择 |
| 驱动性问题 | 我们怎样用一张A4纸搭一座跨过15厘米间距的桥，并通过公平测试向参观同学说明哪种设计更可靠？ |
| 探究路径 | 第1课时观察并提出猜想；第2课时比较结构；第3课时依据反馈修改并复测；第4课时展示与反思 |
| 成果与评价 | 纸桥、初版与改版的测试记录、简短讲解；重点看公平比较、证据解释和修改理由 |
| 可视化 | 制作项目展示板，预留“我们的测试结果”区域，由课堂中的真实记录补充 |

15厘米是示例参数，应由教师课前试做调整；不将“承重最大”作为唯一评价标准。这个示例的核心设计判断是：**让结构选择建立在比较证据上，并让修改前后的记录成为学习证据。**

### 3. 迁移示意

低年级可以使用图片记录、口头解释和教师协助计数；高年级可在具备相应知识和时间后加入重复测试、结果差异讨论。迁移时需要重新检查目标和课时，不能仅替换年级名称或提高承重要求。

## 七、课堂实施与审核

### 1. 实施前检查

- 驱动性问题是否值得探究，并且能在现有条件下推进？
- 学习目标是否有对应任务和证据？
- 学生是否有真实的选择、反馈和修改机会？
- 知识内容、数据和课程标准引用是否已经核实？
- 课时是否包含材料准备、整理和展示？
- 活动所用设备、工具、实地调查等是否符合年龄与学校要求？
- 是否可以在不增加不必要家庭负担的条件下完成？

### 2. 实施中记录

记录学生提出的新问题、作出选择时的理由、遇到的困难和修改过程。教师可以调整原计划，并记下调整原因，不必为了完成AI安排而中断有价值的学生探究。

### 3. 使用边界

AI可以协助备课、整理和提出修改建议；教师负责判断内容和学情是否匹配。上传试教记录时使用去标识化描述，学生作品、影像或声音的公开展示遵循所在学校的授权安排。

海报和示例图片只能说明设计或预期呈现。真实课堂效果需要真实记录支持。

## 八、作为平台项目发布时，建议展示什么

### 1. 项目卡片

| 字段 | 建议填写 |
| --- | --- |
| 名称 | AI辅助PBL课程设计：从主题到可试教方案 |
| 类型 | Prompt／AI工作流 |
| 一句话用途 | 通过六步提示词，帮助教师明确问题、学习目标、探究路径、成果与评价 |
| 面向用户 | 需要PBL备课、课程改造或跨学段迁移支持的教师 |
| 学段 | 按实际提供的案例标注；其他学段标为可尝试迁移 |
| 输入 | 主题、学情、课时、目标、资源条件 |
| 输出 | 可审核的课程初稿、评价工具、可选海报文案 |
| 工具条件 | 多轮文本AI；海报图片需额外图像或排版能力 |
| 当前状态 | 待作者确认；没有试教证据时使用“设计示例／待试教” |
| 预览 | 展示一次真实运行的输入和部分输出，可附截图；示例输出注明未经课堂验证 |

### 2. 项目详情

详情页应让教师能够回答：

- 这套工作流解决了什么备课困难？
- 我的学生、课时和资源是否适合？
- 我需要填写什么，先复制哪段提示词？
- 哪些环节需要我作出教学判断？
- 实际运行生成了什么，有哪些不足？
- 别人如何试教或修改过？我迁移时应注意什么？

建议依次呈现“适用场景—输入与输出示例—使用步骤—可复制提示词—教师判断—试教与改进记录”。输入输出的文字对照可作为基础预览，截图或短录屏作为增强材料，无需为静态文本强行制作GIF。

这些是项目内容组织建议，不表示平台已经具备自动填表、调用AI或生成海报的功能。

### 3. 作者与复用者记录模板

```text
【项目版本】：
【作者及原项目来源】：
【提示词来源说明】：原创／改编；如为改编，补充来源与修改内容。
【复用授权】：填写作者明确允许的使用、修改与分享范围；不明时标注待确认。
【本次使用的AI工具、模型及日期】：以实际使用记录为准。
【实践状态】：设计示例／已运行提示词／已试教／经过多轮调整。
【实际使用情境】：年级、主题、人数、课时与材料。
【我保留的核心设计】：
【我修改的内容及理由】：
【观察到的学生表现】：提供去标识化的实际记录。
【判断依据】：作品片段、测试记录、学生解释、教师观察等。
【尚未解决的问题】：
【下一次准备调整什么】：
```

版本记录应说明具体改动和原因。教师的修改理由、实施限制和学生学习证据，是后续使用者判断能否复用的重要依据。
