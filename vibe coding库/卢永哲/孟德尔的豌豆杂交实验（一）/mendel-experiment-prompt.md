# 孟德尔豌豆杂交实验互动网站生成 Prompt

## 项目目标

请制作一个面向高中生的生物知识互动网站，主题为 **《孟德尔的豌豆杂交实验（一）》**。网站应结合教材知识、可视化实验和游戏闯关，让学生通过操作理解显性遗传、隐性遗传和分离定律。

- **面向人群：** 高中生
- **研究性状：** 豌豆茎的高度
- **基因表示：** `T` 表示高茎显性基因，`t` 表示矮茎隐性基因
- **表达要求：** 使用简洁、准确、适合高中生理解的中文

## 一、开场页面

网站打开后先显示独立的“问题探讨”页面。

### 主问题

> 子代会不会只是父母性状的“混合”？

介绍过去的“融合遗传”观点：人们曾认为双亲的遗传物质会在子代中混合，就像红墨水与蓝墨水混合后无法再次分开。

### 思考题

1. 如果纯种高茎豌豆和纯种矮茎豌豆杂交，子代会长成什么样？
2. 你是否同意“遗传物质会混合”的观点？证据可能来自哪里？

在题目旁设置 **“查看参考答案”** 按钮。点击后在原页面弹出白色模态框，背景变暗并模糊，分别展示两道题的答案。支持关闭按钮、点击遮罩关闭和按 `Esc` 键关闭。

右下角设置 **“进入遗传实验室 →”** 按钮，点击后进入实验主页。

## 二、实验主页顶部

顶部左侧显示网站标志和标题 **“孟德尔的豌豆杂交实验（一）”**，右侧设置两个模式按钮：

- 学习模式
- 闯关模式

中间设置绿色主题横幅：

- **标题：** 让基因自己“说话”
- **副标题：** 从一粒豌豆开始，亲手完成杂交实验，观察基因型如何决定表现型。

### 学习模式横幅内容

绿色横幅右侧展示三条教材总结：

- **背景：** 当时流行“融合遗传”的观点。
- **证据：** F₁ 全为高茎，F₂ 高茎∶矮茎约为 3∶1。
- **定律：** 成对遗传因子形成配子时彼此分离。

### 闯关模式横幅内容

将教材总结替换为：

- 闯关进度，例如 `1 / 3`
- 实验积分，例如 `0`

## 三、学习模式

设置 `TT`、`Tt`、`tt` 三个基因型选项。学生可以拖动或点击，将任意两个基因型放入“亲本 A”和“亲本 B”。

| 基因型 | 表现型 |
| --- | --- |
| TT | 高茎 |
| Tt | 高茎 |
| tt | 矮茎 |

选择两个亲本后，显示双方能够产生的配子。点击 **“开始杂交实验”** 后：

1. 根据亲本基因型产生配子。
2. 在孟德尔棋盘格中展示四种子代组合。
3. 自动统计子代基因型。
4. 自动计算高茎与矮茎的表现型比例。
5. 在下方花园中平均排列四株子代植物。

### 植物视觉要求

- 高茎使用更高、更挺拔的植物图形。
- 矮茎使用明显更低的植物图形。
- 图形旁保留基因型以及“高茎/矮茎”文字。
- 植物不能遮挡文字，各区域需要为植物预留真实高度。

### 实验步骤

设置三个实验步骤：

1. 配子分离
2. 随机结合
3. 表现型出现

未开始实验时，三个步骤保持相同的基础样式。实验进行到某一步时，才高亮对应步骤。

### 教材知识点

棋盘右侧设置“教材知识点”区域。未开始实验时提供四项可展开内容：

1. 为什么选择豌豆？
2. 高茎与矮茎怎样杂交？
3. 分离定律如何解释？
4. 怎样通过测交验证？

实验完成后，将通用知识替换成与本次亲本组合和子代结果相对应的解释。

## 四、闯关模式

制作三关遗传挑战。每关展示一组亲本，让学生从 `TT`、`Tt`、`tt` 中选出所有可能的子代。

### 关卡示例

1. 第一关：`TT × tt`
2. 第二关：`Tt × Tt`
3. 第三关：`Tt × tt`

### 交互规则

- 子代选项可以多选。
- 提交后立即判断结果。
- 正确选项显示绿色。
- 错误选项显示红色。
- 答对后获得 100 分并进入下一关。
- 顶部同步更新闯关进度与实验积分。
- 提供简短、具体的即时反馈。

### 基因小图鉴

右侧设置“基因小图鉴”：

- `T`：显性基因，高茎
- `t`：隐性基因，矮茎
- 提示学生先判断亲本产生的配子，再进行组合

## 五、离开实验室问题

在闯关模式的“基因小图鉴”底部设置按钮：

> 离开实验室前，想一想 →

点击后弹出白色模态框，背景变暗并模糊，展示一道迁移应用题。

### 问题

某农场的马有栗色和白色两种毛色，分别由遗传因子 `B` 和 `b` 控制。育种工作者选出一匹栗色公马，想仅根据毛色判断它是纯合子还是杂合子。

1. 一匹母马通常一次只生一匹小马。为了在一个配种季完成鉴定，应该怎样安排配种？
2. 后代可能出现哪些结果？怎样根据结果作出判断？

### 折叠参考答案

参考答案默认折叠，学生点击 **“查看参考答案”** 后展开：

- 让栗色公马与多匹白色母马 `bb` 进行测交。
- `BB × bb` 的后代全部是 `Bb`，表现为栗色。
- `Bb × bb` 的后代约有一半栗色、一半白色。
- 出现白色后代即可判断公马为 `Bb`。
- 后代全部为栗色时更支持公马为 `BB`，但观察的后代越多，结论越可靠。

## 六、视觉风格

- 使用绿色、薄荷绿、米白色和浅黄色作为主要颜色。
- 风格清新、自然，具有生物实验室和校园游戏的感觉。
- 使用大圆角卡片、轻微阴影和柔和渐变。
- 信息层级清楚，避免内容拥挤。
- 高茎与矮茎植物在所有区域保持统一的视觉规则。
- 页面适配桌面端、平板和手机。
- 所有按钮提供悬停、键盘焦点和点击反馈。

## 七、技术要求

使用原生 HTML、CSS 和 JavaScript 实现，不依赖后端和大型框架。代码结构保持简洁：

```text
version-2/
├── index.html
└── src/
    ├── styles.css
    └── app.js
```

页面应能通过本地静态服务器直接运行。确保以下功能均可正常使用：

- 拖动和点击选择亲本
- 孟德尔棋盘格计算
- 表现型比例计算
- 学习模式与闯关模式切换
- 关卡进度与积分更新
- 折叠知识内容
- 白色模态框与背景模糊
- 键盘操作和基础无障碍支持
