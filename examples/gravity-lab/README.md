# 重力实验室

一个可独立打开、可上传到他山的离线物理实验。三条轨道让地球、月球、火星上的物体从相同高度、相同质量、零初速度同时释放。它是教学用的理想模型，不是课堂效果已经验证的材料。

## 教学资料

- **项目名称**：重力实验室：地球、月球与火星自由落体比较
- **学科**：物理
- **适用学段**：初中、高中
- **教学用途**：比较重力加速度、质量、释放高度如何影响自由落体，并把运动学量和能量变化联系起来。
- **适用学生**：已接触质量、重力、速度概念的初中生；学习匀变速直线运动、牛顿第二定律与机械能的高中生。
- **前置基础**：理解米、秒、千克、牛顿的含义；高中定量活动还需会平方根、比例关系及焦耳单位。
- **学习目标**：说明忽略空气阻力时同地点的落地时间与质量无关；用 `F = mg` 区分质量与重力；解释 `t ∝ √H`；在触地前用势能减少与动能增加检查机械能守恒。
- **教学方式**：预测、观察、解释；控制变量探究；教师投屏或学生两人一组操作，建议 12–18 分钟。该时长是活动设计建议，未经课堂试教确认。

## 一次可执行的课堂活动

1. **预测（2 分钟）**：高度 20 m、质量 1 kg。先记录哪一个天体最早落地及理由，再开始播放。
2. **质量比较（3 分钟）**：保持高度不变，把质量设为 2 kg。记录地球的预计落地时间与重力，解释为什么一个不变、一个翻倍。
3. **高度比较（3 分钟）**：保持质量与天体不变，比较 20 m、40 m。计算落地时间之比，检查它接近 `√2` 而不是 `2`。
4. **能量观察（3 分钟）**：暂停并拖动时间轴，选择同一个天体，记录一组 `U`、`K` 和 `U + K`。解释为什么势能逐步转成动能。
5. **退出问题（1–2 分钟）**：“把一片羽毛和一个钢球拿到真实空气中，为什么结果可能与这里不同？”要求指出模型假设。

## 交互说明

- 高度 1–100 m，整数；质量 0.1–10 kg，步长 0.1 kg。文本输入验证不合法时不改变实验条件。
- 调整高度或质量会暂停并从零计时。三组轨道始终共用相同的模拟时间。
- “开始下落 / 暂停”控制连续播放；“重置”回到初始位置；“前进 0.1 秒”先暂停再前进一步。
- 时间轴可前后回看；键盘箭头调整滑块，Home/End 到两端。原生按钮用 Enter/Space 操作。
- 点击某个天体只切换下方读数，不重置或改变其他组的运动。
- 0.5× / 0.25× 仅改变播放速度，不改变公式和模拟中的落地用时。
- 系统偏好减少动态时，默认开启分步模式，连续播放按钮禁用；用户可自行取消勾选后主动播放。页面切到后台会暂停。
- 动态数字不逐帧向读屏软件播报，开始、暂停、单步等操作通过状态区域说明。

## 物理模型与局限

近地表重力加速度取课堂代表值：地球 `9.80 m/s²`、月球 `1.62 m/s²`、火星 `3.71 m/s²`。真实值会随位置和高度变化；三处使用同样“忽略空气阻力”的前提，并非在真实大气中比较。

设释放高度为 H，地面高度 y = 0，初速度为零，向下速度的大小为 v：

```text
t_landing = sqrt(2H / g)
y = max(0, H - 0.5*g*t²)
v = g*t
F = m*g
U = m*g*y
K = 0.5*m*v²
U + K = m*g*H
```

计算时间只取 `[0, t_landing]`。采用解析解，拖动时间轴不累积数值积分误差。每一组触地后停止运动，速度与动能明确标注为**触地前一瞬**的读数。碰撞、反弹、发热、形变、空气阻力、自转效应、地表曲率和 g 随高度变化均不建模。因此能量守恒的展示仅针对下落阶段，不描述碰撞之后的机械能。

轨道高度统一缩放，圆点尺寸是示意标记；小圆环表示各自总下落时间 20%、40%、60%、80% 时的位置，因此间距不相等。它们不是等距离标记或相同绝对时刻的记录。
