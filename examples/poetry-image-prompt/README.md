# 古诗入画 ·《山居秋暝》教学海报 Prompt

这个项目帮助教师把“读懂诗句”转为可核对的视觉创作要求。示例采用王维《山居秋暝》，先辨认文本中的景物、动作与声音，再制作海报，最后让学生用诗句检查画面。海报可作为讨论材料，不能替代原诗阅读。

## 文件与使用方式

- `prompt.md`：可复用模板、已填写的《山居秋暝》输入、关键误读提示与来源。上传平台时可作为项目附件，或复制其中模板到 Prompt 正文。
- `README.md`：教师使用说明、项目资料建议、封面艺术描述及验收边界。
- `example.png`：内置图像工具生成的无字示例图，1672×941像素，2,972,487字节，低于5 MiB封面上限。可作为封面和看图辨析素材。
- `image-generation.md`：实际图像Prompt、文件校验信息及制作端视觉检查；保留生成来源，不将图片记为DeepSeek生成。

建议先使用文字模型完成核对和绘图方案，教师审核后再把绘图 Prompt 交给图像工具。有字海报若出现错字，应改用无字底图并人工排版。复制模板时不要把本文件整份作为诗词原文输入。

## 一次约35—40分钟的课堂使用建议

1. **读诗与提问，约8分钟**：朗读原文，圈出时间、景物、人物和动作。解释关键生词；先让学生说出自己的画面，不急于展示AI图。
2. **找依据，约8分钟**：两人一组将“诗句直接写到的”“依据注释理解的”“自己补充的”分成三类。讨论为什么“空山”不等于画面必须完全无人。
3. **看图与对照，约10分钟**：教师展示审核过的图或构图草案。学生指出松与月光、泉与石、竹林人影、莲叶与渔舟之间的联系，并找出原诗没有规定的颜色、人数和方位。
4. **修改与再读，约8分钟**：各组提出一条带原句依据的修改要求。比较修改前后的图，再朗读诗句，说明修改改变了什么。
5. **退出条，约3分钟**：写或说出“图中这一处对应哪句诗”“这一处是画者的选择”“我仍想核对什么”。评价依据与解释，不按画面精致程度评分。

这些分钟数用于备课安排，不代表已经实施。若当堂生成较慢，使用预先审核的图继续讨论；原文、生词卡及纸笔活动可独立使用。

## 示例诗文与理解边界

王维《山居秋暝》为五言律诗；本项目完整诗文以教育局所列繁体底本核对后转写为简体。主要意象关系可参照教育局经典名句释义中的说明。对尾联的具体指向可结合所用教材继续讨论，不把一幅图当作唯一解释。[教师研修讲义，第11—22页](https://www.edb.gov.hk/attachment/tc/curriculum-development/kla/chi-edu/resources/secondary-edu/lang/CDI020221739_ppt.pdf#page=11) · [关键诗句释义，第3页](https://www.edb.gov.hk/attachment/tc/curriculum-development/kla/chi-edu/chinese-culture/Classic%20Sayings_2021-22_explanation.pdf#page=3)

本项目只使用古诗原文和自行编写的教学说明，不复制来源页面的书法、插图或整段现代赏析。艺术画面中的人数、布局、颜色与服饰概括都是创作选择，不是对唐代某日、某地的史实记录。**AI绘图不等于历史复原，不等于课堂验证，也不能证明学习成效。**

## 给图像生成工具的封面描述

以下为无字封面制作建议。已由内置图像工具生成`example.png`，实际提交的Prompt及结果见`image-generation.md`：

```text
创作一幅横版16:9的古诗课堂插画，灵感来自王维《山居秋暝》。当代纸本水墨淡彩，米白宣纸细纹，画面清润、安静、温和，构图精简而层次清楚。

雨后的初秋傍晚，青灰色远山在轻薄水汽中层叠；中景松枝之间有柔和银蓝月光，月亮保持自然尺度，不做巨月。右下方前景是湿润山石与一股清泉，水沿石面流向中景，少量细小白色波纹。中景一侧有竹林小径，两位衣着朴素的成年洗衣女子仅以很小的归来背影出现，布篮作为艺术补充，不刻画人物身份。另一侧水面少量莲叶轻轻分开，一叶渔舟露出部分船身，用水纹表达移动；不要添加大片盛放莲花。

配色为低饱和矿物青绿、鼠尾草绿、银蓝、水墨灰与暖纸白。用干湿笔触、淡彩晕染和适度留白呈现空间，不采用照片拼贴、3D塑料材质或游戏界面。左上方留约25%的安静纸白，方便教师后期排版。图内完全无字：不画题目、诗句、字母、数字、印章、Logo、水印或边框。

不加入满山鲜红枫叶、暴雨、宫殿、王冠儿童、神怪、战争、现代建筑、车辆和电子设备。人物只作小比例生活线索，衣着得体，适合小学高年级与初中课堂。此图是依据诗意的教学构图，不声称复原真实历史地点。
```

如需项目卡片题名，可在图外使用“古诗入画”及“山居秋暝”；若制作完整有字海报，应由教师在确认原文后排版，避免把模型生成的错误文字上传为成品。
