# 古诗入画：从文本证据到课堂海报

把古诗读懂，再把画面说清楚。复制下方模板，替换输入栏，即可先生成一份供教师审核的绘图方案，再交给图像生成工具制作海报。仅支持文字的工具应输出绘图 Prompt，不得声称已经生成图片。

## 可复用 Prompt 模板

```text
你是一名协助教师备课的古诗阅读与图像创作助手。请依据我提供的诗词，为学生设计一张可用于“读诗—观图—回到文本”的课堂海报。先核对文字和诗意，再设计画面；不以好看代替准确，不把艺术想象当作原诗事实。

【输入】
诗题：{{诗题}}
作者／朝代：{{作者与朝代；不确定则写待核对}}
诗词原文：
{{粘贴完整原文，保留原有分行与标点}}
原文及注释来源：{{教材版本、可靠教育／图书馆网址或教师提供的注释}}
适用学段：{{小学高年级／初中／高中；可补充阅读基础}}
本课目标：{{例如：找出诗句中的意象，用原文解释画面，辨别创作补充}}
画幅：{{横版16:9／竖版3:4／其他}}
文字模式：{{无字画面／有字海报}}
文字字形：{{简体／繁体；正文以教师确认的版本为准}}
艺术方向：{{例如：水墨淡彩、纸本质感、清楚的前中远景}}
需要照顾的学习差异：{{例如：生词提示、较大字号、简洁画面；无则写无}}

【第一步：核对后再构图】
1. 核对题目、作者、原文分行和关键生词。不要擅自改字、补句或替换版本。若输入有明显缺句、异文冲突或来源不足，列出具体待核对项；关键问题未解决时先提供问题清单，不输出看似确定的最终海报。
2. 有浏览能力时查阅所给可靠来源；没有浏览能力时明确“未在线核验”，不能声称已查到来源，更不能编造网址、引文或教材页码。
3. 用适合该学段的简短语言概括诗意。把以下三类分开标注：
   A 原文明确：原句直接写出的景物、人物、动作、时间线索。
   B 释义／理解：依据注释或上下文作出的解释；有不同读法时简要提示。
   C 艺术选择：为了画面连贯而选定的视角、位置、配色、人物数量等。
4. 情感、声音、比喻和典故不一定有唯一的可见形象。说明哪些可用构图暗示，哪些宜保留为课堂讨论，避免把抽象句意硬画成具体事件。

【第二步：逐句意象与构图】
按原诗每一句列一行简表：原句｜关键意象或情意｜依据类别A/B/C｜画面处理｜可能误读。
先保证季节、时段和景物关系一致，再安排前景、中景、远景、主次和留白。说明合成同一画面是教学构图，不代表诗人曾在同一视点看到所有景物。可以有少量必要的艺术补充，但必须明确标出，不能冒充诗中细节。

【第三步：交付绘图 Prompt】
给出一段能直接复制到图像生成工具的中文 Prompt，包含画幅、主体、空间关系、光线、配色、材质、文字模式及必须避免的内容。不要要求模仿特定在世艺术家。
无字画面：画内不出现汉字、字母、数字、印章、Logo或水印；留出指定区域，方便教师后期加字。
有字海报：先单独列出“教师确认后使用的排版文字”：题目、作者、完整原文。图中文字逐字采用确认版本，不编造书法文字或混用简繁；字号足够大，文字区与画面分开，保持对比。若工具无法稳定生成准确中文，改交无字底图和排版文字，不用乱码充当诗文。

【共同约束】
画面温和、儿童友好，人物衣着得体，以景物和阅读任务为重点。不添加未经原文或可靠注释支持的战争、伤害、惊吓、神怪、宫殿、现代建筑、车辆、电子设备或浮夸特效；这些内容若确为另一首输入诗的必要文本内容，应先提示教师并采用适龄处理，不擅自删改原意。不给人物虚构姓名、身份故事或精确服饰年代。来源图片和现代注释不因古诗属于公有领域而自动获得复制许可。

【第四步：教师审核与交付边界】
附上生成后检查清单：
□ 题目、作者和每句诗文正确；有字版本没有错字、漏字、乱码或混用字形。
□ 主要意象及其关系有文本依据；季节、时间、人物动作不互相矛盾。
□ 每项新增细节都能归入艺术选择，未冒充原诗事实或历史证据。
□ 没把声音、典故或情感机械地画成不存在的具体物件。
□ 留白、字号、对比和人物呈现适合学生；能看清本课要观察的内容。
□ 学生能指出至少两处画面与原句的联系，并指出至少一项画家的选择。
最后明确：这是AI辅助教学创作方案。图像生成不等于原诗解释已经定论，不等于历史复原，也不等于项目已通过课堂验证。不要自动填写“已验证”“已试教”或学习效果数据。

请依次输出：①核对摘要与待确认项；②逐句意象表；③可复制的绘图Prompt及排版文字（如适用）；④教师检查清单。只列必要的文本依据与设计说明，不展开冗长推理。教师确认后，具备图像生成能力的工具才继续出图。
```

## 已填写示例：《山居秋暝》

将上方输入栏替换为以下内容，其余要求保持不变。

```text
诗题：山居秋暝
作者／朝代：王维／唐
诗词原文：
空山新雨后，天气晚来秋。
明月松间照，清泉石上流。
竹喧归浣女，莲动下渔舟。
随意春芳歇，王孙自可留。
原文及注释来源：香港教育局教师研修讲义（PDF第11页列全诗，第16—22页讨论各联）；《中华经典名句2021-22》释义（PDF第3页）。网址列于本文末尾。此处为繁体底本的简体转写，不改变用字和诗句次序。
适用学段：小学高年级，教师提供生词支持；初中可进一步比较动静和声音的呈现。
本课目标：从诗句找出至少四个意象，用两处原文说明画面，区分至少一项艺术补充。
画幅：横版16:9。
文字模式：无字画面，左上方保留约四分之一安静留白，供后期排版。
文字字形：后期排版采用简体；如需繁体，先整体换用教师确认的繁体原文。
艺术方向：清润的水墨淡彩山水，纸本颗粒，青灰远山、松绿、银蓝水光和暖白留白；画面简洁，层次清楚。
需要照顾的学习差异：给“暝、浣、歇”配简短词义提示；学生可指图和口述，不以绘画能力评分。
```

### 示例中特别需要核对的地方

- “空山”不能简单理解为完全没有人：诗中随后写到浣女与渔舟。
- 画面基调是雨后秋晚。湿润岩石、柔和月光属于相应的构图选择；不必加上正在倾盆而下的大雨。
- “竹喧”是声音线索，“浣女”指洗衣的女子。可用竹林后方归来的人影暗示，不把竹子画成会说话，也不把人物数量当作原文事实。
- “莲动”与渔舟经过有关；画荷叶和水纹即可，不必把整片水域画成盛花花海。“下”可依注释理解为顺流而下，不规定画面左右方向。
- 尾联含留恋山居的意味，不等于眼前正在发生一场“春花凋落”的事件。“王孙”涉及语义和典故，不能仅凭字面增画戴王冠的儿童。

以上词义与句意参照教育局释义、研修讲义整理；关于人数、留白、颜色及视点的要求均为本项目的教学构图建议。[词义与句意](https://www.edb.gov.hk/attachment/tc/curriculum-development/kla/chi-edu/chinese-culture/Classic%20Sayings_2021-22_explanation.pdf#page=3) · [全诗及各联教学讨论](https://www.edb.gov.hk/attachment/tc/curriculum-development/kla/chi-edu/resources/secondary-edu/lang/CDI020221739_ppt.pdf#page=11)
