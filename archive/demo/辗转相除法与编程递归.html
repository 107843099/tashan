看懂递归调用

函数自己调用自己，递归到底发生了什么？

跟着函数一层层“往下调用”，再一层层“把答案带回来”，你会看见递归的完整旅程。

递归调用追踪

调用第 1 步
↓ 正在调用下一层

当前：gcd(84, 36)

这一层函数还没有答案，它需要调用下一层来帮忙。

当前函数参数gcd(84, 36)
→
下一层函数参数gcd(36, 12)
%
a % b 的计算84 % 36 = 12
把这一层的 a % b 画成矩形：紫色部分就是下一层带走的数据
8436
黄色：切下 2 个边长 36 的正方形→紫色：留下 36 × 12

因此下一层调用 gcd(36, 12)。

✓
递归出口：b 等于 0不用再调用，直接返回 a = 12。
↑
答案开始往上返回把 12 交回给上一层函数。
最外层函数最终得到gcd(84, 36) = 12

调用栈

每调用一次函数，就把这一层放到栈顶；它要等下一层返回答案。

int gcd(int a, int b) { if (b == 0) return a; return gcd(b, a % b); }

黄色行：继续调用下一层；绿色行：递归出口，开始返回答案。
