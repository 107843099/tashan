# 产品定义

复现课堂帮助教师将别人的优秀教学实践变成自己的真实课堂实践。平台的核心不是生成教学内容，而是降低成果、环境、对象、步骤、理由、失败经验和课堂反馈在传播过程中的损失。

## 核心能力

1. 可复现：条件、清单、步骤、成功标准与排错足够清楚。
2. 可理解：教师能看见关键设计理由和技术的必要解释。
3. 可迁移：教师能基于自己的条件获得有理由的调整建议。
4. 可验证：复现和课堂实施记录成为项目可信度的一部分。

## 北极星路径

发现 → 判断 → 复现 → 理解 → 修改 → 迁移 → 教学 → 反馈 → 再设计 → 继续被复现。

## 边界

本产品不是 AI 教案/PPT 生成器、LMS、在线 IDE 或教师社交平台。AI 只提供整理、解释或建议；任何项目发布、验证结论和课堂效果都由教师确认。
