# 当前状态（预检）

更新日期：2026-08-27

## 当前技术栈

- 静态单体 Web 应用：HTML、CSS、原生 JavaScript。
- 本地浏览器数据存储作为演示数据层；没有真实数据库、认证、对象存储或外部 AI 凭证。
- 通过 `npm run start` 运行，`npm run build` 执行结构与语法检查。

## 当前页面与功能

初始仓库只有首页中的项目卡片、筛选、项目详情弹窗及「我要复现」提示。没有可分享路由、上传、草稿、账户、复现记录、数据模型文档或测试脚本。

## 可复用部分

- 首页视觉语言与产品定位文案。
- 六个示例项目的呈现方式。
- 「快速判断 → 跟着复现 → 深入理解」的信息层级。

## 技术债与缺口

- 单页弹窗不能支撑指定路由与深链接。
- 没有实体之间的结构化关系，也没有空状态、错误状态或权限边界。
- 没有可重复的构建、测试和版本文档。
- 当前环境没有 Supabase、邮件服务或 AI Provider 的真实凭证，因此这些能力不能被伪造为线上服务。

## 建议架构

在不引入不必要依赖的前提下，采用带 hash 路由的单体前端与 `localStorage` Mock Repository：

```text
UI 路由 / 表单
  ↓
领域数据与统一常量
  ↓
Mock Repository（localStorage）
  ↓
Mock AI Provider（显式标识，须由教师确认）
```

将来接入 Supabase 时，只需用远端 Repository 和 Auth Provider 替换 Mock 实现；领域模型与页面流保持不变。
