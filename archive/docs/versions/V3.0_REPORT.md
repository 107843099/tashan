# V3.0 报告

**版本：** V3.0（本地 Mock）  
**目标：** 支持有质量检查的学科迁移。  
**已完成功能：** 目标学科档案、迁移草案、保留/修改/风险、四项融合质量检查、创建新项目。  
**新增页面：** `/projects/[slug]/transfer`、迁移结果页。  
**新增组件：** 迁移质量检查卡。  
**数据库 / API：** SubjectTransfer 本地记录。  
**测试 / Build：** 已通过。  
**已知问题：** 未经专家验证的草案不能被描述为有效课程。  
**暂缓内容：** 自动教育质量认证。  
**下一版本目标：** 课堂反馈。  
**复盘：** 删除新学科仍不变时会提示融合浅；没有只增加学科标签。
