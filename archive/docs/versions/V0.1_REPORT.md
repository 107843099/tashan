# V0.1 报告

**版本：** V0.1  
**目标：** 让用户理解平台是什么，并知道如何开始一个项目。  
**已完成功能：** 首页、项目发现、六个明确标记为 Demo 的项目、筛选、三层项目详情与「我要复现」。  
**新增页面：** `/`、`/projects`、`/projects/[slug]`（Hash 路由）。  
**新增组件：** ProjectCard、项目元信息、步骤卡与验证状态。  
**数据库 / API：** 无；使用本地示例数据。  
**测试 / Build：** 已通过静态构建检查与浏览器项目详情检查。  
**已知问题：** 无真实数据与服务端路由。  
**暂缓内容：** 账户、上传、真实验证。  
**下一版本目标：** 支持项目贡献。  
**复盘：** 解决“我看不懂平台与项目”的问题；用户可发现、判断并开始。没有加入资源商城或 AI 聊天功能。
