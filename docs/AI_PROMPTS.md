# 管理 AI 提示词

管理员登录后，进入「我的账户 → 账户管理 → AI 提示词」，按功能调整教学指令：

| 功能 | 使用位置 | 调整重点 |
| --- | --- | --- |
| 上传信息分析 | 上传项目后的分析与预填 | 名称、教学用途、学科、学段与课堂条件 |
| 教学建议 | 工作台的 AI 教学建议 | 学生差异、先备知识、学习目标与活动次序 |
| 创作 Prompt | 创作 Prompt 的 AI 优化 | 角色、任务、交付形式与验收要求 |

每项最多 4,000 个 Unicode 字符，可使用换行与制表符。建议直接写教学要求，例如「活动先预测、再观察、最后用证据解释」，不需要自己编写 JSON 或填入 API 密钥。

点击保存后，下一次请求读取新版本；已经开始的生成保留当时的提示词版本。上传分析默认自动补充空字段，用户可以提前关闭，并在提交前核对；教学建议与 Prompt 优化由用户选择采用。AI 不会自动保存或发布项目。

## 保存、恢复与冲突

- 页面显示当前内容、默认内容、修改人和时间，草稿不会写入浏览器持久存储。
- 多个管理员同时编辑时，服务端比较版本号。发生冲突后保留本人草稿，先加载最新版本进行核对，再决定如何保存。
- 「恢复默认」恢复该功能的内置教学指令，仍保留递增版本，防止旧页面覆盖后续修改。
- 操作记录只记录功能、版本与是否恢复默认，不复制整段提示词。
- 账号退出或切换后会清除管理区资料与未保存草稿。

## 固定规则

管理员可调整建议的内容、侧重点和语气。平台仍固定输出字段、语言选择、学科与学段枚举，并检查 AI 返回格式；模型、服务地址、密钥与额度由服务端配置。项目文字仍按资料处理，不会成为可执行代码或链接访问命令。

配置读取失败时会明确报错，不会悄悄改用默认内容。读取提示词与模型调用共享生成时限；配置读取有独立的短超时，并响应请求取消。

## 部署

先应用 `supabase/migrations/202609110007_ai_prompts.sql`，再发布新版 Worker。007 新建私有配置表与三个服务端 RPC，不修改已有账号、密码、项目或附件。缺少配置记录表示使用内置默认内容；表或 RPC 不可用属于配置错误。

本机模式使用 SQLite 的 `ai_prompts` 表；云端模式使用 Supabase。二者不会自动互相覆盖。不要把服务端配置表、私有开发配置或 API 密钥放入静态发布目录。
