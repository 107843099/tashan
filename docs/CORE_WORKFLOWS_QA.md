# 核心页面与本地流程验收

日期：2026-09-10。范围：正式主页面（现为 `index.html`）及其本地存储、生成示例、教学建议；不是对全部原项目的功能或课堂成效认证。

## 实际浏览器检查

- 项目库：14 条目录，5 张实际生成的图片加载；分类与元数据接入。
- 古诗条目：三语教学建议、示例作品、原 Prompt、来源与验证分区；完整预览实际加载 1672 × 941 PNG。
- 继续创作：教学建议带入表单，生成任务说明并保存工作台。
- 本地上传：通过浏览器文件选择器提交 HTML 和 2 MB PNG；填写学科、学段、对象、基础、目标和使用方式后保存。
- 刷新恢复：项目、附件、封面与描述保留；修改名称并再次保存，刷新后仍显示新名称。
- 隔离运行：自包含 HTML 中计数按钮从 0 变为 1；读取 localStorage 被 sandbox 阻止。
- 备份：界面生成 JSON，检查版本、项目、附件与封面编码。导入含同一 ID 的备份测试资料时产生另一条项目，保留原条目；原有草稿保留。
- 删除：清理两条临时验收记录后，项目库回到 14 条；既有收藏、草稿和创作任务保留。
- 布局：桌面 1280 px 与手机 375 px、平板 768 px 检查；手机英文详情导航的横向溢出已修复，简繁英界面均可切换。

内置浏览器的下载/剪贴板自动化读取没有稳定返回下载事件或剪贴板内容，因此备份提供了可直接查看并手动选择复制的 JSON 备用入口。未将工具读取失败认定为数据导出失败；已在可见 JSON 中核对完整附件编码长度。独立 HTML 的入口已调整为当前标签页打开，预览页提供返回项目入口，以兼容内置浏览器。

## 自动检查

`npm run build` 与 `npm test` 通过：

1. 主入口、浅色默认、引用资产及 JS 语法。
2. 原始文件哈希、Prompt 原文、封面和下载、关联项目。
3. 14 项三语教学字段与参考链接；5 张 PNG 与原资料目录中的副本字节一致。
4. IndexedDB 接口：附件往返、编辑、草稿、备份导入、ID 冲突、无效输入、容量限制与事务失败回滚。
5. 保存项目并清理草稿是同一事务；大附件不会因草稿重复计量而错误失败。
6. 本地记录进入详情和继续创作：缺失可选字段不崩溃、成果说明与原附件可用、用户文字转义、安全 URL、导入表单字段规范化。

## 内容限制

教学适配是编辑建议；课时为建议，不是试验结论。唐朝示例为插画改编，未冒充原模板要求的真实文物照片。化学、圆锥曲线原文件中的错误已明确标记，未直接改写原文件。
