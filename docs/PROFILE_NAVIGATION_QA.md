# 个人入口与密码表单验收

日期：2026-09-11

## 交互

- 登录后点击右上角个人入口，先进入工作台。
- 工作台账户信息条提供独立的「个人资料」入口，沿用 `#account` 地址，原有链接仍可使用。
- 个人资料默认展示基本信息、所属资料和登录会话；管理员另有账户管理入口。
- 修改密码集成在个人资料卡片中，点击后才创建密码输入框。取消后移除输入框，重新打开为空；提交成功后收起并显示结果。
- 离开个人资料后再进入，密码表单恢复收起状态。管理员重置密码后的必要改密流程保持原有行为。
- 三语文案、使用指南与账号说明同步更新。

## 验证

- 账号界面、入口意图和初始化回归：29 项通过，无跳过。
- 本地隔离浏览器验收：右上角进入工作台、专用入口进入个人资料、默认收起、取消清空、真实修改密码成功后收起、成员权限及会话流程通过。未修改任何线上用户密码。
- 24 组布局：管理员/成员、简体/繁体/英文、深浅色、390px/1440px；折叠与展开表单均无横向溢出，按钮具备可访问名称。
