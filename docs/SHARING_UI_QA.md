## 管理员开户与成员分享

管理员在正式站账户管理界面新建 `test_share`，角色为成员、归属为个人；创建请求返回 HTTP 201。随后使用新账号登录，未要求首次强制改密。

两件作品分别完成以下步骤：

1. 从「我的工作台」的分享入口进入三步表单，选择源文件和封面。
2. DeepSeek 自动分析教学文字，填充项目名称、教学用途、学科、学段、适用学生、先备知识、学习目标与教学方式八项资料。
3. 在表单中人工审核，完成确认并保存版本。
4. 点击「保存当前版本到云端」，等待附件、封面与版本保存完成。
5. 点击「发布此版本」，确认公开，再检查发现页的「公开作品」。

当前三步表单先将项目和版本暂存在浏览器；云端保存与发布确认仍是后续两个独立操作。本轮按现有流程逐步验收，没有将其改成一键发布。AI 预填也不会自动保存到云端或公开作品。
