# 加载与交互优化验收 · 2026-09-11

本轮保留原有版式与账号、云端项目功能，优化启动阶段和展示资源。

## 改动

- 确认会话时显示轻量加载状态；已有账号或游客会话刷新不会临时加载原石场景。登录表单先绘制，再分阶段准备三维场景。
- 账号脚本提前并行请求状态和会话，等待应用安装身份隔离 hooks 后才应用结果；加载占位不重复渲染。入口焦点在表单挂载并绘制后处理，避免先布局空场景再布局表单。
- 保留18片碎裂、原矿物纹理与圆形玉璧，去除石壳内部不可见侧壁。初始化允许取消，关闭时完整释放画布与GPU资源。闲置30fps，碎裂时完整动画，后台不绘制。
- 5张示例图片有320/640/960 WebP版本。默认640预览合计从12,028,330字节降到373,096字节（减少96.9%）；PNG原图、下载与来源哈希不变。15张展示图约1.20MB，发布包因保留原图会略增，实际页面只下载适配尺寸。
- 轮播、卡片、详情与相关项目按显示尺寸选择图片，异步解码；查看大图和载入完整示例时仍使用原PNG。
- 深浅色切换不重建页面，保留输入、展开状态与焦点；主题选择跨刷新保留。
- 构建自动更新懒加载三维模块版本，再更新入口版本，避免部署后仍加载旧模块。

## 图片维护

`python3 scripts/build-cover-variants.py --check` 校验现有预览，无额外图片库依赖。更换原图后，使用脚本声明的固定Pillow/libwebp版本显式执行再生成，再运行 `npm run build`。原图与预览各自拥有哈希，展示图不会代替来源凭据。
