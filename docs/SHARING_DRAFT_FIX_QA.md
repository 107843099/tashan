# 分享入口与草稿删除验收

日期：2026-09-11

## 问题与修复

原分享表单最后一步只保存到当前账号的浏览器资料。即使用户从「分享项目」进入，也仍需进入详情上传云端、再选择版本公开，容易把本地保存误认为已分享。本次核对的成员账号正常，但云端没有其项目记录。

- 表单最后一步分别提供「仅保存到此浏览器」和「上传并公开」。分享确认后先上传完整版本，再执行发布；失败保留本地副本，明确提示上传失败或发布失败。
- 工作台本地项目增加上传并公开入口；云端私有项目提供发布最新版本；公开项目可以查看固定版本和复制公开链接。
- 发布后使旧详情请求失效，防止较晚返回的私有状态覆盖最新公开状态。
- 未完成草稿增加删除入口，确认后清除草稿；取消、刷新持久性、保存项目和云端版本的保留均有回归验证。
- 三语说明、使用指南与移动端操作布局同步更新。

没有把已有浏览器资料自动上传或公开。原浏览器中的项目需由账号持有人选择「上传并公开」。云端公开作品仍位于发现页下方的独立列表。
