# 管理后台与 AI 提示词验证

## 功能

「账户管理」按账户、AI 提示词、操作记录分区。账户列表与编辑区调整间距、选中状态和移动端定位，继续保留学校／机构资料、密码、角色与启停用功能。

管理员可分别保存上传信息分析、教学建议、创作 Prompt 的教学指令，查看默认内容、修改人和时间，并恢复默认。正文最多 4,000 个 Unicode 字符；保存采用版本比较，冲突时保留本人草稿。切换账号、降级或重置密码后，旧请求不能重新填回管理资料。

每次生成读取当前配置，只向普通用户返回生成结果及提示词版本号。模型、服务地址、密钥、额度和结构化输出校验保持在服务端。读取失败、超时或取消时不调用模型，也不会悄悄使用默认指令。

文件恢复可读后，已实际执行 AI 接口 22 项及提示词存储/API 7 项，共 29/29 通过，零跳过。包含 SQLite、PGlite 迁移与权限、异常 HTTP 状态、无效 JSON、正常 `200 null` 和退出登录 `204`。后续发布版本与云端复查结果另行记录；无需重复付费模型调用。
