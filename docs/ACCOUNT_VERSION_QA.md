## 已完成

- 本地 SQLite 保存真实账号和会话，密码使用带随机盐的 scrypt 哈希；账号随本地服务重启保留。
- 管理员创建账号、编辑名称和角色、停用/启用、重置密码、查看操作记录；成员首次登录或被重置后先改密。
- 服务端校验身份、管理员权限、请求来源、字段、大小和操作频率；退出、停用、重置使相关旧会话失效。
- 用户名、密码和游客按钮直接嵌入原石开场；验证成功复用同一场景自动碎玉，进入首页顶部。验证失败停留原石；首次改密也在同一场景完成。离场移除节点、GPU资源与过渡状态。
- 游客明确进入后可浏览公开项目、运行作品与复制 Prompt；收藏、上传和私人工作台引导登录。直接打开旧匿名预览链接也需要登录，不读取旧资料。
- 创建账号有字段旁校验、可选中文显示名、生成初始密码；成功后清除搜索条件并选中新账户，初始账号信息可复制，离开管理页清除。
- 登录账号使用独立浏览器资料空间，旧匿名项目和草稿可显式导出。
- 预览按当前会话读取对应资料；跨标签页退出/切换后清空旧作品和下载链接。每次有效展示创建新的沙箱 iframe，隐藏时销毁旧上下文；取消过期会话检查，防止旧请求覆盖新内容。
- 私密配置、数据库和服务端源码不经本地静态接口提供，也不进入静态发布 ZIP。

## 验证

`npm test` 通过目录、文件存储/备份、现有项目流程、15 项账号 API 测试和真实 SQLite 集成测试。覆盖管理员/成员/未登录访问、首次改密、重置与停用、会话续期和退出、错误输入、审计及限流。真实 SQLite 并发续期回归验证同一旧凭据的并发请求不会误触发退出，并确认停用/退出仍立即使会话失效；未登录预览不访问匿名资料。

独立 Chrome 无头浏览器使用临时数据库执行 `tests/account-browser.mjs`，通过原石场景内登录与错误密码、同场景节点复用、动效清理和首页置顶、游客刷新与操作门控、管理员建号/字段错误/密码生成/清除搜索、成员改密、IndexedDB 按账号区分、预览退出清理、管理员接口越权拒绝、英文与手机深色页面检查。测试使用 1440px 桌面与 390px 手机视口，不读写使用者日常浏览器资料。另以独立浏览器会话检查三语切换保留未提交输入、375×667 和 844×390 英文布局与游客按钮、减少动效快速进入、强制 WebGL 失败时 SVG 后备进入，以及匿名旧 ID 不能预览。

浏览器检查需要另行安装 Playwright 与相应浏览器，也可通过 `PLAYWRIGHT_MODULE` 指定已安装模块，使用 `BROWSER_CHANNEL=chrome` 选择 Chrome。测试在本机 4181 端口运行临时服务，结束删除测试数据库。执行：`node tests/account-browser.mjs`。

`npm run build` 生成静态目录和 ZIP，并检查相对资源、文件边界、单文件大小及资源版本。后端随 Worker 源码部署，单独上传静态 ZIP 不会启用账号服务。
