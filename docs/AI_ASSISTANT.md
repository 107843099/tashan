# DeepSeek 教学助手

本版本已接入真实 DeepSeek 文本生成。界面保留已有项目与工作台流程，生成结果由教师核对后保存；模型不能执行项目代码、发布作品、设置使用许可或声称完成课堂验证。

## 三个入口

1. **上传项目 → 自动分析**：默认开启，可在文件选择前关闭。支持 HTML、Markdown、TXT、JSON；提取教学文字后预填名称、用途、学科、学段、学生、先备知识、学习目标和教学方式。只补空项，或替换仍未被手动编辑的文件名占位标题。学科和学段判断不清时允许留空，提交前仍需补齐。
2. **补充教学信息 → AI 教学建议**：查看发送内容，生成后选择要采用的字段。保留其他已填内容。
3. **基于项目继续创作 → AI 优化创作 Prompt**：基于项目文字及课堂改编要求生成可编辑 Prompt。采用后可继续编辑，保存到工作台或转成新项目。

封面、实际课堂记录、许可与“我已检查”确认仍需本人提供。AI 预填不等于提交，也不等于公开发布。ZIP、PDF、Word、PowerPoint 当前可以作为附件上传保存，但此版本不自动提取其中内容；页面要求填写项目说明后再分析，不能把未读取的文件说成已分析。

HTML 摘录只读取文件前 1 MiB，最多保留 6,000 字符；跳过脚本、样式、模板、SVG 和属性，不执行页面或抓取外部资源。文字过长会标记摘录；纯 Canvas/脚本生成的页面可能无法提取足够教学内容，需要补充说明。上传原件保持完整，不受摘录长度影响。

## 服务端配置

在不受 Git 跟踪的 `.dev.vars` 中保存 `DEEPSEEK_API_KEY`，云账号开发使用 `npm run dev:cloud`。本机已经配置，本仓库和静态发布包不会包含这个值。普通 `npm run dev` 不自动加载 `.dev.vars`；如需使用本机 SQLite 账号加 AI，可用 `node --env-file-if-exists=.dev.vars scripts/dev-server.mjs`。

Cloudflare 使用 Workers Secret `DEEPSEEK_API_KEY`，由 `server/worker.mjs` 在服务端读取。浏览器只向同站 `/api/v1/ai/assist` 发教学文字，绝不直接连接 DeepSeek，也不接收密钥。Cloudflare 正式站点的部署与 Secret 配置仍须单独完成，本机成功不代表线上已经更新。

接口固定使用 `https://api.deepseek.com/chat/completions`、`deepseek-flash`、关闭思考模式、JSON 输出和最多 1,600 输出 tokens；模型与上游地址不能由浏览器提交。依据 [DeepSeek Chat Completions 文档](https://api-docs.deepseek.com/api/create-chat-completion/) 和 [当前模型说明](https://api-docs.deepseek.com/quick_start/pricing/)（2026-09-10 核对）。

## 接口与限制

`GET /api/v1/ai/capabilities` 和 `POST /api/v1/ai/assist` 均需已登录、有效且不处于管理员重置后待改密状态的账号。游客不能消耗模型额度。POST 校验同站 Origin，并严格验证字段。

请求：`{ task: "upload" | "teaching" | "prompt", locale: "zh-CN" | "zh-Hant" | "en", context: { …教学文字字段… } }`。整个请求最多 48 KiB，文字合计最多 10,000 字符，其中核心说明最多 6,000；不能传文件二进制、任意 URL、API key、模型名或管理字段。

响应包括 `result`、`model`、`usage` 和 `generatedAt`。上传/教学返回 `result.fields`，Prompt 返回 `result.text`。学科与学段使用平台标准值，模型返回额外字段或不完整 JSON 时整包拒绝，不部分写入表单。

每账号每分钟最多 3 次、每个 24 小时额度窗口最多 30 次，全站每个窗口最多 300 次；计数保存在现有服务端限流表。额度按**调用尝试**计数，失败也可能占用额度。没有自动重试或免费用量承诺；DeepSeek 按实际 tokens 收费，返回 token 数并非扣费账单。

上游超时为 55 秒，客户端为 70 秒。取消、切换账号、换文件或离开对应页面会取消请求，并防止旧结果污染当前编辑内容；上游已处理的部分仍可能计费。余额不足、密钥拒绝、请求过频、每日额度耗尽、超时和格式错误分别提示。结果以纯文字呈现，不执行返回的 HTML。
