# 上传流程与发布要求验收

日期：2026-09-11

## 本轮范围

分享项目由三步合并为两步：

1. **作品与教学信息**：文件或 Prompt、AI 分析及建议、可编辑教学信息、真实预览、运行或测试说明在同一页。AI 自动补空项，教师可按字段选择替换已有内容。
2. **确认与发布**：核对项目，选择使用授权并确认责任，再选择直接公开或私有云存储；保留仅保存到此浏览器的入口。草稿仍可在未填完时单独保存和删除。

学科增加英语、科学、道德与法治、音乐、美术、体育与健康及劳动。浏览器表单与服务器共享同一学科、学段及发布规则；AI 仍只返回教学文字建议，不填写或勾选真实性、测试与责任声明。

## 必备资料与保存边界

| 类型 | 完整资料要求 |
| --- | --- |
| 教学可视化 | 项目文件或完整 HTTP(S) 项目链接；真实截图、动图或视频链接；名称、用途、学科、建议学段、操作者与学习对象、前置知识、预期学习结果、基本使用方式；明确运行状态与实践状态，已用于课堂时附记录 |
| Prompt | 名称、用途、完整正文；真实输出截图或动图；实际测试过的 AI 工具；单条或组合结构，多步骤组合需写明顺序及依赖 |
| 公开前确认 | 明确使用授权；真实预览、版权、隐私和内容检查必须为本人明确确认；Prompt 另需确认教师人工核查 AI 输出 |
| 选填 | 建议年级、课程关联、参考来源；Prompt 的学科、学段及教学补充 |

说明文字不能单独替代可视化项目资产，装饰图片不能替代作者确认的真实效果。链接只做格式校验；本轮不自动探测外部网站是否始终可用，也不把作者自报状态转换为平台验证或课堂成效认证。使用许可是作者授权声明，不是阻止下载的技术保护。

发布 API 读取已上传且属于当前用户的不可变版本，校验不通过返回 `422 PUBLICATION_INCOMPLETE` 与逐字段错误。请求中夹带另一份完整元数据不能绕过校验。私有 API 保存仍允许尚未完善的资料；客户端完整保存要求第一步信息齐全，未完成内容可保存草稿。已有公开版本保持可读，再次发布需满足当前要求；保存私有新版不会改变旧公开版本。

本轮未改变数据库结构、账号权限和对象存储架构。当前 Worker 配置继续使用 R2 分文件上传：

| 边界 | 配置 |
| --- | ---: |
| 单附件 | 10 MiB（10,485,760 字节） |
| 单张预览图片 | 5 MiB（5,242,880 字节） |
| 版本文字资料 | 64 KiB |
| 上传清单请求 | 96 KiB |
| 每账号服务端总用量 | 200 MiB |
